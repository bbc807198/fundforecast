# fundforecast
# 基金申购赎回资金流预测


## 一、项目介绍

**业务问题**：货币基金每天面临用户的申购（资金流入）与赎回（资金流出）。运营方需要提前知道下个月每一天的申赎规模，才能安排流动性头寸。本项目的任务是：根据 2013-07-01 ~ 2014-08-31 共 **427 天**的日频申购/赎回数据，预测 **2014 年 9 月整月（30 天）**每一天的申购额与赎回额，以及月度总量。

**数据特点**（直接决定了模型设计）：

| 特点 | 表现 | 对建模的含义 |
|---|---|---|
| 强周内季节性 | 周一/周六相差约 1.8 倍，且 14 个月内形态稳定 | 预测中最可靠的信号，模型必须先学会 |
| 月度水平不可外推 | 2014-01/02 制度性跳变（量级升 10 倍），此后横盘；实测"趋势外推"比"平坦估计"误差 +12pp | 水平层是均值回复的，不能用神经网络直接外推 |
| 小样本 + 脉冲事件 | 仅 427 天；季末/年末/营销活动造成多次脉冲跳升 | 日误差存在不可压缩的地板（WAPE 15~18%） |
| 预测期含特殊日期 | 2014 中秋（9/6~9/8）、9/28 调休上班 | 日历效应是深度模型真正的增量来源 |

## 二、技术路线：为什么建两个模型

本项目对同一问题并行构建了**统计路线（SARIMA）**与**深度学习路线（LSTM）**两条技术路线，并各自提交竞赛。原因：

1. **SARIMA 回答"数据里有多少结构是可解释的"**。作为经典 Box-Jenkins 流程的完整实践（平稳性检验 → 定阶 → 估计 → 残差诊断 → 回测），它给出一个可解释、可辩护的基线，也用来验证数据的关键结构（I(1)、周内季节性）。
2. **LSTM 回答"非线性结构能不能再榨出增量"**。用于捕获节假日、调休、短期动量等固定周内因子无法表达的结构。
3. **对比本身就是项目的核心价值**。项目没有停留在"跑出一个预测值"，而是建立了统一的**滚动回测 + 显著性检验**评估体系，用来回答：深度学习的提升是否真实？来自哪里？值多少？——对这份数据，结论是：提升真实但有限，且增量集中在节假日结构点上（详见子项目文档）。

## 三、结果（项目亮点）

- 两条路线分别提交天池竞赛并取得榜单成绩：**SARIMA 70+ / LSTM 120+**（具体排名口径以官方榜单为准）
- **SARIMA 路线**：完成"描述性统计 → ADF/KPSS 平稳性检验 → AIC/BIC 网格定阶 → 参数估计 → 残差诊断（Ljung-Box / Jarque-Bera / ARCH）"全流程；从残差 lag-7 显著自相关识别出强周内季节性，将 ARIMA 扩展为 SARIMA，**AIC 改善 74~105**；设计两轮 30 天滚动回测验证泛化能力。最终模型：申购 SARIMA(1,1,2)(2,1,1)₇、赎回 SARIMA(1,1,1)(0,1,1)₇；2014 年 9 月预测申购 87.2 亿、赎回 109.9 亿（净流出约 22.7 亿）
- **LSTM 路线**：设计**"周内形状 × 尺度 × 水平"三层分解架构**——慢变且不可外推的资金量级交给 EWMA 估计，LSTM 只学习日历效应与短期动量，从根上避免神经网络直接预测原始值"走平/乱涨"的问题；采用未来日历特征解码头、多 seed 集成（5 模型）与早停。5 折滚动回测：**日 WAPE 18.6%~21.1%，月总量误差约 10%**；2014 年 9 月预测申购 78.6 亿、赎回 82.9 亿
- **评估体系（本项目最核心的方法论）**：
  - 5 折滚动回测（2014-04 ~ 08，每月仅用此前数据训练并预测整月，与 9 月预测任务完全同构）
  - 防泄漏三原则：训练/验证按时间切分并设 31 天 gap、标准化只用训练段统计、目标变换全部为因果变换
  - 复现 3 条统计基线（季节朴素 / 上周同日 / 周内形状×水平），用**配对分块 bootstrap** 证明提升非噪声（申购对最优基线 5/5 折全胜，90% CI 不跨 0，P=0.97）
  - 噪声地板实验（换种子 WAPE 波动 ±0.5~1.5pp），小于该幅度的"提升"一律判噪声
- **业务洞察落地**：模型自动捕获**中秋节假期资金塌陷**（9/8 较普通周一低约 20%）与**调休上班日抬升**（9/28 较普通周日高约 33%）——这是简单周内因子基线做不到的；并据此确立"水平层用 EWMA 平坦估计而非趋势外推"的设计决策

## 六、核心结论（TL;DR）

1. **周内形状占这份数据绝大部分可解释方差**——"周一/周六差 1.8 倍且 14 个月稳定"是最强信号，任何模型都必须先学会它；
2. **月度水平呈均值回复且有制度性跳变，不可外推**——这是模型设计的第一约束，也是三层分解的原因；
3. **深度学习的增量真实但有限**：不在全面超越基线，而在节假日/调休等日历结构点；想再提升需要外部变量（收益率、大盘、同业规模），而不是更大的网络；
4. **日 WAPE 约 20%、月总量误差约 10%** 是当前特征下的合理误差水平，报个位数日误差的大概率是泄漏了。
